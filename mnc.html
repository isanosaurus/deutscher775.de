MoodleNameChange.

A browser extension that shows names on Moodle the way you want them. Set a rule once — every course page, forum post and message follows it.

What it does

  • Only touches Moodle

    Every Moodle runs on its own school domain, so it first checks whether a page really is Moodle. Everywhere else it does nothing.

  • Keeps up with the page

    Drawers, messages and anything Moodle loads later get replaced too — not just what was there on first load.

  • Leaves your typing alone

    Text fields, editors and code blocks are skipped, so nothing you write or submit gets changed.

  • Stays on your device

    No servers, no analytics, no tracking. Your rules live in your browser's own extension storage.

Install

Firefox & Chrome

Firefox

From Firefox Add-ons — updates arrive automatically.

  1. Open the add-on page on addons.mozilla.org.
  2. Click Add to Firefox and confirm.
  3. Click the toolbar icon → Open Settings and add a rule.
  4. Reload your Moodle tab.
Add to Firefox

Chrome, Edge & Chromium

From the Chrome Web Store — works in Edge, Brave and other Chromium browsers too.

  1. Open the extension on the Chrome Web Store.
  2. Click Add to Chrome and confirm.
  3. Pin it from the puzzle icon, then click it → Open Settings and add a rule.
  4. Reload your Moodle tab.

Rather build it yourself? Grab the source ZIP, run ./build.sh and load dist/chrome via → Load unpacked.

Add to Chrome

Settings

3 options
  • Ignore case "max" also matches "Max"
  • Whole words only "Max" leaves "Maxi" alone
  • Tooltips & labels Also replaces hover text and alt text

    On by default — recommended, so the name doesn't pop up again in a tooltip.

Add as many rules as you like. Longer search terms win, so Max Mustermann is replaced before Max ever gets a chance.

Settings sync between your devices if browser sync is on.

Privacy

Collects nothing

MoodleNameChange makes no network requests, contains no analytics and never reads passwords or form inputs. It asks for access to all websites only because every school hosts Moodle under its own address — the check whether a page is Moodle happens locally, and non-Moodle pages are left untouched.

If you only ever use one Moodle, you can narrow the matches pattern in manifest.json to that domain. Details are in the privacy policy and the README.
